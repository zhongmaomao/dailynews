---
name: grill-me-more
description: Stress-test a plan or design efficiently by first aligning key decision points, then asking related question batches, and drilling into unresolved branches one-by-one.
---

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions. For each question, provide your recommended answer.

Start by listing key decision points and current assumptions that need alignment, even when the original goal or codebase already implies them.

Ask related questions in small batches first, usually 3-5 questions per batch. Keep each batch focused on one decision area so the user can answer efficiently.

If the user agrees with most points, only drill into unresolved, disputed, high-risk, or ambiguous points one at a time.

Ask one question at a time only when the next answer blocks the decision tree, when the tradeoff is high-risk, or when a previous answer shows disagreement.

If a question can be answered by exploring the codebase, explore the codebase instead.
