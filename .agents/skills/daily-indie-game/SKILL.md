# Daily Indie Game

Use this skill to produce the `独立游戏简要推荐` section.

## Goal

Recommend 1 game that is worth a reader’s time, even if it is not the biggest launch.

## Scope

Good candidates:

- newly released indie games
- demos from festivals or Steam Next Fest
- older games with a fresh spike because of update, port, or community rediscovery

Avoid obvious AAA titles or games that are “indie” only in marketing language.

## Source Strategy

Use a mix of:

- Steam store pages
- itch.io
- festival pages
- Rock Paper Shotgun, PC Gamer, Eurogamer, GamesRadar
- creator posts or devlogs when useful
- Steam user sentiment as one weak signal, not the final decision-maker

## Selection Heuristics

Prefer games with:

- a distinctive mechanic or aesthetic
- clear niche appeal you can explain
- manageable time / price expectations
- recent reason to surface now

## Output Format

Include:

- game title
- one short description of what it is
- one short recommendation reason
- source links

## Openness Rule

Do not optimize only for “latest release today.” A demo, a festival standout, or a recently updated hidden gem can be a better recommendation if the case is stronger.
