# Daily AI Frontier

Use this skill to produce the `互联网 + AI 技术前沿发展要闻` section.

## Scope

Include high-signal developments in:

- model releases or meaningful updates
- AI tooling, agents, coding, inference, evals, safety, multimodal, data
- major internet platform product moves when AI is central
- research-to-product transitions that are already affecting builders

Do not fill this section with generic startup funding unless the technology signal is strong.

## Source Strategy

Start with high-trust sources, but do not stop there.

Priority sources:

- official blogs, release notes, docs changelogs
- major tech media
- major research journals or lab posts when product relevance is clear
- GitHub releases or repo activity if the project is materially important

Useful source families:

- OpenAI, Anthropic, Google, Meta, Microsoft, NVIDIA, Hugging Face
- TechCrunch, The Verge, Ars Technica, Wired, Reuters
- Nature, Science, arXiv summaries, research lab blogs

## Selection Heuristics

Pick 3 items that maximize spread across:

- product / platform
- model / infrastructure
- methods / safety / research signal

Favor items with a concrete implication for builders:

- new capability
- lower cost
- changed workflow
- new risk
- new competitive signal

## Freshness

- Target last 24 hours.
- Expand to 48 hours when needed.
- If still thin, allow one “ongoing this week” item and label it explicitly.

## Output Format

For each item:

- one-line title
- 2 short bullets:
  - what happened
  - why it matters
- source links

## Quality Bar

- Avoid three items that are all “company X launched another model.”
- Avoid hype without mechanism.
- If a story is mostly marketing, either sharpen the takeaway or discard it.
